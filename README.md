# Visible File Editor

A reusable AI skill for ChatGPT, Codex, and compatible coding agents that makes file editing transparent, safer, and easy for humans to review.

## Features

- Supports DOCX, PDF, Excel, PowerPoint, Markdown, HTML, and code files.
- Encourages minimal, targeted edits while preserving original files.
- Provides change logs, diffs, and reviewable copies where possible.
- Recommends validation checks after editing.
- Includes privacy and file-safety guidelines.

## Installation

1. Download or clone this repository.
2. Follow the skill installation instructions for your AI tool.
3. Review `SKILL.md` and any host-specific requirements.
4. Test the skill on a copy of a sample file before editing important documents.

## Repository Structure

- `SKILL.md` — Main skill instructions.
- `references/` — Additional editing and review guidance.
- `examples/` — Example change-report templates.
- `CONTRIBUTING.md` — Contribution guidelines.
- `SECURITY.md` — Security reporting guidance.
- `CHANGELOG.md` — Project changes.

## Important

This repository provides instructions for an AI editing workflow, not a standalone file-editing application. Actual capabilities depend on the AI tool and its available file access.

Always keep backups of important files and review changes before accepting them.
